# Design: web-portal

## Architecture

```
Browser (web/) · Installed PWA (pwa/: Safari iOS · macOS)
  ├─ index.html ─ main-login.js ─ auth/login.js ─ Cognito (SRP + MFA TOTP)
  ├─ chat.html ──── (spec 03)  ┐  validate session with pages/dashboard.js
  └─ policies.html (spec 04)  ┘  and call the API with shared/api.js
                                        │ HTTPS (POST JSON)
                                        ▼
                            PortalApi (public HTTP API, CORS *)
```

## Folder structure: two standalone apps

The frontend ships as **two independent applications**, each in its own folder, runnable and deployable on its own (each has its own `package.json`, `node_modules`, `.env.local` and Netlify site). They do not share code through imports: the common code is generated **identically in both** from the same blocks of this spec, which is the single source.

```
/
├─ web/      Web app: browser only (no manifest, no service worker, no icons)
├─ pwa/      PWA app: the same app + manifest, service worker, icons and iOS metas
├─ infra/    Single SAM backend (used by both apps)
├─ .kiro/ · .gitignore · README.md
```

Inside each app:

```
package.json · vite.config.js · netlify.toml · .env.local (no versionado)
index.html · chat.html · policies.html
src/
  config.js                      ← reads VITE_* (single configuration entry point)
  auth/      cognito.js · login.js · session.js
  shared/    api.js · qr.js · sidebar.js · theme.js · topbar.js · ui.js · utils.js
  pages/     dashboard.js        ← common initialization of protected pages
  styles/    tokens.css (spec 01) · login.css · dashboard.css · policies.css (spec 04)

  public/  sw.js · manifest.webmanifest · icons/*.png
```

### Rules for creating the files from the blocks

The `#### \`path\`` headings in the `design.md` files of specs 01 to 04 are interpreted as follows:

| Block path | Where it is created |
|---|---|
| `src/**` (except `src/styles/pwa.css`), `index.html`, `chat.html`, `policies.html` | In `web/` **and** in `pwa/` |
| `web/<file>` | Only in `web/` |
| `pwa/<file>` | Only in `pwa/` |
| `public/**`, `src/styles/pwa.css` | Only in `pwa/` (the blocks already carry the `pwa/` prefix) |
| `infra/**`, `.gitignore`, `kiroween-2026-information/**` | Once only, at the root |

**`web/` variant of the common files** (the blocks describe the PWA version; for `web/` apply these removals and nothing else):

1. In the three HTML files, remove: the `<!-- PWA / iOS ... -->` comment, `<link rel="manifest" ...>`, `<link rel="apple-touch-icon" ...>`, the `mobile-web-app-capable`, `apple-mobile-web-app-capable`, `apple-mobile-web-app-title` and `apple-mobile-web-app-status-bar-style` metas, and the `<script>` block that registers the service worker (`navigator.serviceWorker.register`).
2. In `main-login.js`, `main-chat.js` and `main-policies.js`, remove the line `import "./styles/pwa.css";`.
3. `viewport-fit=cover` is kept.

What must **not** exist in `web/`: `public/`, `manifest.webmanifest`, `sw.js`, `icons/`, `pwa.css`, or references to `serviceWorker`, `manifest` or `apple-`. Verification: task 7.

## Decisions

- **Two standalone folders** (`web/` and `pwa/`) due to a contest requirement. Each one is installed, run and deployed without depending on the other. A root `shared/` folder or workspaces were avoided so each app can be evaluated separately; consistency is guaranteed by this spec, which generates the same code in both.
- **MPA with Vite**, not SPA: each module is an independent page (simpler to isolate and to install as a PWA). The SPA version (`welcome.html`) and the `consumption.html` page, which was a "coming soon" placeholder with no functionality, were removed.
- **Exact dependencies**: `amazon-cognito-identity-js 6.3.12`, `qrcode-generator 1.4.4`, `vite 5.4.21`. No frameworks, no TypeScript, no tests inherited from the SPA version.
- **Public API**: by project decision the API does not validate tokens and accepts any origin. Anyone with the URL can invoke it; rate limiting (5 req/s) bounds Bedrock consumption.
- **Theme**: `tokens.css` (spec 01) defines all colors; there are no fixed hex values here except the QR.
- **`status-bar-style=black`**: with `black-translucent` the status bar text would be white on the light theme. `black` is legible in both themes.

#### `pwa/public/sw.js`

````javascript
/**
 * sw.js — Service Worker for offline cache.
 *
 * Strategy: Network First with cache fallback.
 * - Navigation requests (HTML): serves from cache if the network fails.
 * - Assets (JS/CSS/fonts): serves from cache if the network fails.
 * - External requests (Cloudflare ping, Cognito API): go straight to the network,
 *   never cached — the connectivity monitor needs them to fail in order to
 *   detect offline correctly.
 *
 * The cache name includes a version. When CACHE_VERSION changes,
 * the SW installs a new cache and removes the old one on activate.
 */

const CACHE_VERSION = "v2";
const CACHE_NAME    = `sia-cache-${CACHE_VERSION}`;

// Local assets to pre-cache on install
const PRECACHE_URLS = [
  "/",
  "/index.html",
  "/chat.html",
  "/policies.html",
  "/manifest.webmanifest",
];

// External domains that are NEVER cached
const BYPASS_ORIGINS = [
  "1.1.1.1",
  "cognito-idp",
  "amazonaws.com",
  "fonts.googleapis.com",
  "fonts.gstatic.com",
];

// ----------------------------------------------------------------
// Install: pre-cache HTML pages
// ----------------------------------------------------------------
self.addEventListener("install", (event) => {
  event.waitUntil(
    // A resource that fails must not prevent the rest from installing
    caches.open(CACHE_NAME).then((cache) =>
      Promise.all(PRECACHE_URLS.map((url) => cache.add(url).catch(() => {})))
    )
  );
  // Activate immediately without waiting for previous tabs to close
  self.skipWaiting();
});

// ----------------------------------------------------------------
// Activate: clean up old caches
// ----------------------------------------------------------------
self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(
        keys
          .filter((key) => key !== CACHE_NAME)
          .map((key) => caches.delete(key))
      )
    )
  );
  // Take control of all open tabs immediately
  self.clients.claim();
});

// ----------------------------------------------------------------
// Fetch: Network First with cache fallback
// ----------------------------------------------------------------
self.addEventListener("fetch", (event) => {
  const url = new URL(event.request.url);

  // Let external requests pass through untouched
  const isBypass = BYPASS_ORIGINS.some(
    (origin) => url.hostname.includes(origin)
  );
  if (isBypass) return;

  // Only intercept GET
  if (event.request.method !== "GET") return;

  event.respondWith(
    fetch(event.request)
      .then((response) => {
        // Valid response — update cache and return
        if (response && response.status === 200 && response.type !== "opaque") {
          const responseClone = response.clone();
          caches.open(CACHE_NAME).then((cache) =>
            cache.put(event.request, responseClone)
          );
        }
        return response;
      })
      .catch(() => {
        // No network — try the cache
        return caches.match(event.request).then((cached) => {
          if (cached) return cached;
          // If there is no cache for this resource, return the index page as fallback
          if (event.request.mode === "navigate") {
            return caches.match("/index.html");
          }
          // For uncached assets, return an empty response that does not break the SW
          return new Response("", { status: 503, statusText: "Offline" });
        });
      })
  );
});
````

#### `src/auth/session.js`

````javascript
/**
 * session.js — Cognito session management.
 * Validates tokens, extracts claims and handles sign-out.
 */

import { createUserPool } from "./cognito.js";

/**
 * Extracts { nickname, email } from the ID Token of a valid session.
 * Returns null if the `email` claim is missing or empty.
 *
 * @param {object} session - CognitoUserSession
 * @returns {{ nickname: string, email: string } | null}
 */
export function extractClaims(session) {
  const payload  = session.getIdToken().decodePayload();
  const email    = (payload.email    || "").trim();
  const nickname = (payload.nickname || "").trim();
  if (!email) return null;
  return { nickname, email };
}

/**
 * Checks the current user's session and calls onSuccess(claims)
 * or redirects to index.html if there is no valid session.
 *
 * @param {object} userPool - CognitoUserPool (injectable for tests)
 * @param {function} onSuccess - cb({ nickname, email })
 * @param {function} onFail    - cb() called when there is no session
 */
export function validateSession(userPool, onSuccess, onFail) {
  const pool = userPool ?? createUserPool();
  const cognitoUser = pool.getCurrentUser();

  if (!cognitoUser) {
    onFail();
    return;
  }

  cognitoUser.getSession(function (err, session) {
    if (err || !session || !session.isValid()) {
      onFail();
      return;
    }

    const claims = extractClaims(session);
    if (!claims) {
      onFail();
      return;
    }

    onSuccess(claims, cognitoUser);
  });
}

/**
 * Signs out of Cognito and redirects to index.html.
 *
 * @param {object} userPool - CognitoUserPool (injectable for tests)
 */
export function signOut(userPool) {
  const pool = userPool ?? createUserPool();
  const cognitoUser = pool.getCurrentUser();

  if (cognitoUser) {
    cognitoUser.signOut();
  }

  window.location.href = "index.html";
}
````

````javascript
function translateCognitoError(err) {
  switch (err && err.code) {
    case "UserNotFoundException":
    case "NotAuthorizedException":
      return "Incorrect email or password.";
    case "UserNotConfirmedException":
      return "This account has not been confirmed yet. Contact the administrator.";
    case "PasswordResetRequiredException":
      return "A password reset is required. Contact the administrator.";
    case "TooManyFailedAttemptsException":
    case "TooManyRequestsException":
    case "LimitExceededException":
      return "Too many attempts. Wait a few minutes and try again.";
    case "InvalidPasswordException":
      return "The password does not meet the system security requirements.";
    case "CodeMismatchException":
    case "EnableSoftwareTokenMFAException":
      return "The code is incorrect. Check your app and try again.";
    case "ExpiredCodeException":
      return "The code has expired. Enter the current code from your app.";
    case "NetworkingError":
    case "network error":
      return "No internet connection. Check your network and try again.";
    default: {
      const msg = (err && err.message) || "";
      if (msg.toLowerCase().includes("network") || msg.toLowerCase().includes("failed to fetch")) {
        return "No internet connection. Check your network and try again.";
      }
      return msg || "An error occurred. Please try again.";
    }
  }
}

function handleFailure(err) {
  stopLoading();

  const inChallenge = currentPanel === newPasswordForm
    || currentPanel === mfaSetupForm
    || currentPanel === mfaCodeForm;

  if (inChallenge && err && err.code === "NotAuthorizedException") {
    resetToLogin("Your session expired. Please sign in again.");
    return;
  }

  const target = panels.get(currentPanel).error;
  if (target) showError(target, translateCognitoError(err));

  if (currentPanel === loginForm) {
    _setStage("denied");
    setTimeout(() => _setStage(null), 600);
  }
}

function authCallbacks(cognitoUser) {
  return {
    onSuccess: (session) => {
      stopLoading();
      _setStage("granted");
      onLoginSuccess(session);
    },

    onFailure: handleFailure,

    newPasswordRequired: (_userAttr, requiredAttributes) => {
      stopLoading();
      pendingUser   = cognitoUser;
      needsNickname = Array.isArray(requiredAttributes) && requiredAttributes.includes("nickname");

      nicknameField.classList.toggle("hidden", !needsNickname);
      newPasswordNotice.textContent = needsNickname
        ? "Set your new password and choose your nickname."
        : "Set your new password.";

      _showPanel(newPasswordForm);
      newPasswordInput.focus();
    },

    mfaSetup: () => startMfaSetup(cognitoUser),

    totpRequired: () => {
      stopLoading();
      pendingUser = cognitoUser;
      _setStage("step2");
      mfaCodeForm.reset();
      _showPanel(mfaCodeForm);
      mfaCodeInput.focus();
    },

    selectMFAType: () => {
      cognitoUser.sendMFASelectionAnswer("SOFTWARE_TOKEN_MFA", authCallbacks(cognitoUser));
    },

    mfaRequired: () => {
      handleFailure({ message: "This account uses an unsupported verification method. Contact the administrator." });
    },
  };
}

function initLoginForm() {
  loginForm.addEventListener("submit", (e) => {
    e.preventDefault();
    clearError(errorMsg);

    const email    = emailInput.value.trim();
    const password = passwordInput.value;

    _setLoading(submitBtn, true);
    _setStage("step1");

    pendingEmail = email;
    const cognitoUser  = new CognitoUser({ Username: email, Pool: userPool });

    cognitoUser.authenticateUser(authDetails, authCallbacks(cognitoUser));

function initNewPasswordForm() {
  newPasswordForm.addEventListener("submit", (e) => {
    e.preventDefault();
    clearError(newPasswordError);

    const newPassword = newPasswordInput.value;
    const confirm     = newPasswordConfirmInput.value;
    const nickname    = nicknameInput.value.trim();

    if (newPassword.length < 8) {
      showError(newPasswordError, "The password must be at least 8 characters long.");
      return;
    }
    if (newPassword !== confirm) {
      showError(newPasswordError, "The passwords do not match.");
      return;
    }
    if (needsNickname && !NICKNAME_REGEX.test(nickname)) {
      showError(newPasswordError, "The nickname must be 3 to 20 characters: letters, numbers, hyphen or underscore.");
      return;
    }
    if (!pendingUser) {
      resetToLogin("Your session expired. Please sign in again.");
      return;
    }

    _setLoading(newPasswordBtn, true);
    const attrs = {};
    if (needsNickname) attrs.nickname = nickname;
    pendingUser.completeNewPasswordChallenge(newPassword, attrs, authCallbacks(pendingUser));
  });
}

function buildOtpAuthUri(secret) {
  const issuer  = encodeURIComponent(MFA_ISSUER);
  const account = encodeURIComponent(pendingEmail);
  return `otpauth://totp/${issuer}:${account}?secret=${secret}&issuer=${issuer}`;
}

function startMfaSetup(cognitoUser) {
  stopLoading();
  pendingUser = cognitoUser;
  _setStage("step2");

  qrBox.textContent = "";
  secretCode.textContent = "";
  mfaSetupForm.reset();
  _showPanel(mfaSetupForm);

  cognitoUser.associateSoftwareToken({
    associateSecretCode: (secret) => {
      secretCode.textContent = secret;
      renderQr(qrBox, buildOtpAuthUri(secret));
      mfaSetupCodeInput.focus();
    },
    onFailure: handleFailure,
  });
}

function initMfaSetupForm() {
  mfaSetupForm.addEventListener("submit", (e) => {
    e.preventDefault();
    clearError(mfaSetupError);

    const code = mfaSetupCodeInput.value.replace(/\s/g, "");
    if (!/^\d{6}$/.test(code)) {
      showError(mfaSetupError, "The code has 6 digits.");
      return;
    }
    if (!pendingUser) {
      resetToLogin("Your session expired. Please sign in again.");
      return;
    }

    _setLoading(mfaSetupBtn, true);
    pendingUser.verifySoftwareToken(code, "Authenticator", {
      onSuccess: (result) => {
        if (result && typeof result.getIdToken === "function") {
          stopLoading();
          _setStage("granted");
          onLoginSuccess(result);
        } else {
          handleFailure({ message: "Could not complete the setup. Please try again." });
        }
      },
      onFailure: handleFailure,
    });
  });
}

function onLoginSuccess(session) {
  const claims   = session.getIdToken().decodePayload();
  const email    = claims.email    || pendingEmail;
  const nickname = claims.nickname || "";

  pendingUser = null;
  [newPasswordForm, mfaSetupForm, mfaCodeForm].forEach((f) => f.reset());
  passwordInput.value = "";

  if (REDIRECT_ON_SUCCESS) {
    window.location.href = REDIRECT_ON_SUCCESS;
    return;
  }

  authedNickname.textContent = nickname;
  authedNickname.classList.toggle("hidden", !nickname);
  authedEmail.textContent = email;
  _setStage("granted");
  _showPanel(authedPanel);
}

function restoreSession() {
  const user = userPool.getCurrentUser();
  if (!user) return;

  user.getSession((err, session) => {
    if (err || !session || !session.isValid()) return;
    onLoginSuccess(session);
  });
}

export function initLogin() {
  try {
    userPool = createUserPool();
    bindDom();
    initLoginForm();
    initNewPasswordForm();
    initMfaSetupForm();
    initMfaCodeForm();

    document.querySelectorAll(".js-cancel").forEach((btn) => {
      btn.addEventListener("click", () => resetToLogin());

    if (errEl) errEl.textContent = "Error loading: " + (err.message || err);
  }
}
````

````javascript
 * Portal access is controlled by the Cognito login; the API accepts any origin.

/**
 * POST JSON.
 * @param {string} url
 * @param {object} payload
 * @returns {Promise<object>} JSON body of the response
 */
export async function postJson(url, payload) {
  if (!url) throw new Error("The API URL is not configured.");

  const response = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload),
  });

  const contentType = response.headers.get("content-type") ?? "";
  if (contentType.includes("text/html")) {
    throw new Error("The API returned HTML instead of JSON. Check the configured URL.");
  }

  const data = await response.json().catch(() => ({}));
  if (!response.ok) {
    throw new Error(data.error || data.message || `Server error: HTTP ${response.status}`);
  }
  return data;
}
````

````javascript
/**
 * qr.js — Generates and renders a QR code as inline SVG.
 */

import qrcodeLib from "qrcode-generator";

// qrcode-generator exports the function as default in CJS.
// Vite may wrap it in an object with .default — normalize both cases.
const qrcode = typeof qrcodeLib === "function" ? qrcodeLib : qrcodeLib.default;

/**
 * Draws an SVG QR code in the given container.
 * @param {HTMLElement} container - Element where the SVG is injected
 * @param {string} text          - Text/URI to encode (e.g. otpauth://)
 */
export function renderQr(container, text) {
  const qr = qrcode(0, "M");
  qr.addData(text);
  qr.make();

  const count = qr.getModuleCount();
  const quiet = 2;
  const size  = count + quiet * 2;
  let path = "";

  for (let r = 0; r < count; r++) {
    for (let c = 0; c < count; c++) {
      if (qr.isDark(r, c)) path += `M${c + quiet} ${r + quiet}h1v1h-1z`;
    }
  }

  container.innerHTML =
    `<svg viewBox="0 0 ${size} ${size}" shape-rendering="crispEdges" xmlns="http://www.w3.org/2000/svg">` +
    `<rect width="${size}" height="${size}" fill="#fff"/>` +
    `<path d="${path}" fill="#000"/></svg>`;
}
````

````javascript
/**
````

````javascript
 * Persists the preference in localStorage.
 * Applies the `theme-light` class on <html>.

const STORAGE_KEY = "color-theme";

/**
 * Applies the theme.
 * @param {"light"|"dark"} theme
 */
function applyTheme(theme) {
  if (theme === "light") {
    document.documentElement.classList.add("theme-light");
  } else {
    document.documentElement.classList.remove("theme-light");
  }
  syncThemeColor();
}

/**
 * Aligns <meta name="theme-color"> (browser bar / PWA) with the current --bg.
 * This way the color always comes from tokens.css and is not duplicated in the HTML.
 */
export function syncThemeColor() {
  const bg = getComputedStyle(document.documentElement).getPropertyValue("--bg").trim();
  if (!bg) return;
  let meta = document.querySelector('meta[name="theme-color"]');
  if (!meta) {
    meta = document.createElement("meta");
    meta.name = "theme-color";
    document.head.appendChild(meta);
  }
  meta.content = bg;
}

/**
 * Reads the saved preference or falls back to the operating system's.
 * @returns {"light"|"dark"}
 */
export function resolveTheme() {
  const saved = localStorage.getItem(STORAGE_KEY);
  if (saved === "light" || saved === "dark") return saved;
  return window.matchMedia("(prefers-color-scheme: light)").matches ? "light" : "dark";
}

/**
 * Registers the listener on a toggle button already in the DOM.
 * Updates its icon according to the active theme.
 * @param {HTMLElement} btn
 */
export function bindThemeToggle(btn) {
  syncThemeColor();
  if (!btn) return;
  _updateIcon(btn, resolveTheme());

  btn.addEventListener("click", () => {
    const current = document.documentElement.classList.contains("theme-light") ? "light" : "dark";
    const next = current === "light" ? "dark" : "light";
    applyTheme(next);
    localStorage.setItem(STORAGE_KEY, next);
    _updateIcon(btn, next);
  });
}
````

````javascript
 * - Online: revalidates session → valid: hide modal + green dot;
 *           expired: redirects to index.html.
 * - "Sign out now" button: signs out and redirects to the login.
 * - Polling every 15 s to catch drops that do not fire the 'offline' event.
 *
 * @param {object} pool - active CognitoUserPool
 */
function startConnectivityMonitor(pool) {
  let isOnline = null; // null = unknown, always forces the first update
  let pollTimer = null;

  async function applyOnlineState(online) {
    if (online === isOnline) return;
    isOnline = online;

    if (!online) {
      setOnlineStatus(false);
      showOfflineModal();
    } else {
      // Network is back — revalidate session before turning the dot green
      validateSession(
        pool,
        () => {
          // Valid session — all good
          setOnlineStatus(true);
          hideOfflineModal();
        },
        () => {
          // Session expired — redirect to login
          window.location.href = "index.html";
        }
      );
    }
  }

  async function poll() {
    const online = await checkRealConnectivity();
    await applyOnlineState(online);
  }

  // Manual "Sign out now" button
  const signOutBtn = document.getElementById("offlineSignOutBtn");
  if (signOutBtn) {
    signOutBtn.addEventListener("click", () => signOut(pool));
  }

  // Native browser events (fast response)
  window.addEventListener("offline", () => applyOnlineState(false));
  window.addEventListener("online",  () => poll());

  // Periodic polling for cases where events do not fire
  pollTimer = setInterval(poll, 15_000);

  // Initial state
  poll();

  // Clean up on page unload
  window.addEventListener("beforeunload", () => clearInterval(pollTimer), { once: true });
}

/**
 * Initializes a protected dashboard page.
 * If the session is not valid, redirects to index.html.
 * @param {object} [userPool] - Injectable for tests; uses the real pool if omitted
 */
export function initDashboardPage(userPool) {
  let pool;
  try {
    pool = userPool ?? createUserPool();
  } catch (err) {
    console.error("[dashboard]", err);
    window.location.href = "index.html";
    return;
  }

  validateSession(
    pool,
    (claims) => {
      revealPage();
      renderTopbar(claims.nickname, claims.email);
      setupThemeToggle();
      setupSidebarToggle();
      setupSidebarEar();
      startConnectivityMonitor(pool);

      const signOutBtn = document.getElementById("signOutBtn");
      if (signOutBtn) {
        signOutBtn.addEventListener("click", () => signOut(pool));
      }
    },
    () => {
      window.location.href = "index.html";
    }
  );
}
````
